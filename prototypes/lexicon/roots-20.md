Exsecutor — Twenty Roots
========================

Companion sheet to `affixes.md`. Together, these two documents are the
complete and only reference material for the derivation test — see
`affixes.md` for how to combine what's on this page with a prefix and a
suffix.

These twenty roots are **every root §3.3 of the spec names** — fourteen
Latin, given as present/supine pairs, plus six Greek, given as a single
combining form. Nothing on this page was invented for the test; §3.3 is
reproduced below in full except for reordering, and the one addition
(English glosses for the Greek row) is called out explicitly where it
happens.

---

## Latin roots — present and supine stem

Latin verbs have two stems. A suffix on `affixes.md` names which one it
attaches to; pick the matching column.

| root (present) | supine | gloss |
|---|---|---|
| `leg-` | `lect-` | read |
| `scrib-` | `script-` | write |
| `sec-` | `sect-` | cut |
| `plic-` | `plicat-` | fold |
| `numer-` | `numerat-` | count |
| `ordin-` | `ordinat-` | order |
| `sequ-` | `secut-` | follow |
| `cap-` | `capt-` | take |
| `pon-` | `posit-` | place |
| `ten-` | `tent-` | hold |
| `vert-` | `vers-` | turn |
| `mitt-` | `miss-` | send |
| `iung-` | `iunct-` | join |
| `solv-` | `solut-` | loosen |

That is fourteen roots — the complete Latin root table of §3.3, in the exact
spelling it is published there.

## Greek roots — one form, no present/supine split

§3.3 names six Greek roots in running prose, as combining forms Latin has no
equivalent for. Greek verbs are not conjugated the way the Latin roots above
are, and §3.3 does not give these a two-stem pair — there is exactly **one**
spelling for each, used as-is wherever the root is needed.

| root | gloss |
|---|---|
| `crypt-` | hidden, secret |
| `graph-` | write, draw |
| `metr-` | measure |
| `morph-` | form, shape |
| `chron-` | time |
| `top-` | place (the Greek nominal — as in *topology*; distinct from the Latin **verb** `pon-`/`posit-`, "place," above) |

**Disclosed gap:** §3.3 names these six forms but does not gloss them — the
sentence is "Greek roots cover what Latin lacks: `crypt-`, `graph-`,
`metr-`, `morph-`, `chron-`, `top-`, plus the combining forms `poly-`,
`mono-`, `iso-`, `auto-`," with no English gloss column for this set (unlike
the Latin table, which has one). The glosses above are the standard
classical senses of these combining forms, supplied here because a subject
cannot be asked to gloss what they were never given — but they are **mine**,
not §3.3's, and are marked as such. If a real administration wants
spec-authored Greek glosses, that is `§3.3` follow-up work, not something
this sheet can manufacture on the spec's behalf.

§3.3 additionally names four more Greek items — `poly-`, `mono-`, `iso-`,
`auto-` — but calls them **combining forms**, a different category from
"roots" in the same sentence, and never gives them a place in §3.5's prefix
table (which is exclusively the eight Latin prefixes) or anywhere else. They
are excluded from this twenty and from every task: there is no documented
rule for what they attach to or what law (if any) they'd carry, and
inventing one would be coining, not transcribing. This is a real, disclosed
gap in §3, not an oversight in this sheet — see `README.md` and
`RUBRIC.md` for how it's handled.

## Count

14 Latin + 6 Greek = **20**, matching §16's "twenty roots" exactly, with no
